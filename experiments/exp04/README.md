# Experiment 4: AI Image Generation

## Objective
To generate AI images from text prompts using Stable Diffusion.

## Technologies
- Python
- PyTorch
- Stable Diffusion
- Hugging Face Diffusers
- Gradio

## Features
- Generate images from text prompts
- Select different image styles
- Enter negative prompts
- Generate 1 to 4 images
- View and download generated images
